# Method 1 : Z-Score

### What is Z-Score?

It tells us

> "How many standard deviations away from the average is this value?"

Formula

[
Z=\frac{x-\mu}{\sigma}
]

where

* x = value
* μ = mean
* σ = standard deviation

Usually

```
|Z| > 3
```

means

**Anomaly**

---

### Code

```python
from scipy.stats import zscore

df["Z_Score"] = zscore(df["units_sold"])

df["Anomaly_Z"] = abs(df["Z_Score"]) > 3
```

Now view anomalies

```python
df[df["Anomaly_Z"]]
```

---

### Visualization

```python
plt.figure(figsize=(15,6))

plt.plot(df["date"], df["units_sold"])

plt.scatter(
    df[df["Anomaly_Z"]]["date"],
    df[df["Anomaly_Z"]]["units_sold"],
    color="red",
    label="Anomaly"
)

plt.legend()
plt.show()
```

# Method 2 : IQR Method

### What is IQR?

It uses quartiles.

```
Q1 = 25%
Q3 = 75%
```

Then

```
IQR = Q3-Q1
```

Normal Range

```
Lower = Q1 - 1.5*IQR

Upper = Q3 + 1.5*IQR
```

Anything outside

↓

Anomaly

---

### Code

```python
Q1 = df["units_sold"].quantile(0.25)

Q3 = df["units_sold"].quantile(0.75)

IQR = Q3-Q1

lower = Q1 - 1.5*IQR

upper = Q3 + 1.5*IQR
```

Create anomaly column

```python
df["Anomaly_IQR"] = (
    (df["units_sold"] < lower) |
    (df["units_sold"] > upper)
)
```

Show anomalies

```python
df[df["Anomaly_IQR"]]
```

# Method 3 : Isolation Forest (Recommended)

This is the most advanced method in your project.

### Why?

Unlike Z-score,

it

* works with skewed data
* works with multiple features
* detects hidden anomalies

---

### Features to use

```python
X = df[
[
"units_sold",
"inventory_level",
"warehouse_dispatch_rate"
]
]
```

---

Train the model

```python
from sklearn.ensemble import IsolationForest

model = IsolationForest(
    contamination=0.02,
    random_state=42
)

model.fit(X)
```

Predict

```python
df["IF_Anomaly"] = model.predict(X)
```

Convert

```
1 = Normal

-1 = Anomaly
```

```python
df["IF_Anomaly"] = df["IF_Anomaly"].map(
{
1:"Normal",
-1:"Anomaly"
}
)
```

View anomalies

```python
df[df["IF_Anomaly"]=="Anomaly"]
```
